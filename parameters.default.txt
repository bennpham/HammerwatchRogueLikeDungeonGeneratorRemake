# Boss invulnerability: at 75%, 50% and 25% health the boss goes immortal for

# keeps the three thresholds from firing in the same frame — which would switch

# thresholds; three set them separately; 0 disables that one threshold; `off`

# bossWave1..5 is monsters|defaultIntervalMs|monsterMax|intervalMs|spawnMode.
# Waves 1-4 are the boss's health tiers (100/75/50/25%); wave 5 fires when the
# boss DIES, spawning a last stand into the walk to the orb. Tiers switch on and
# never off, so at 25% health all four health tiers are spawning at once.
# monsterMax, intervalMs and spawnMode are comma-separated id:value pairs and
# are all optional on import (a bare monsters|intervalMs line still works, and
# monsterMax fills in at 10 per monster). A pool entry may be a variant key:
# lich#2 is the elite lich, slime#0 the slime hive, bat1#0 the bats spawner.
# spawnMode is anchors (default: trickles in on the timer from the nine spawn
# anchors) or one of random | ring | gaussian | symmetric, which scatter the
# whole group across the arena at once and ignore the intervals. A monster whose
# wreck still blocks movement (the nova/frost/tracking towers) may not be
# scattered. A max of -1 means endless, and cannot be combined with a scatter
# mode. An empty wave is legal and emits nothing.

# bossWaveBuff1..5 hangs an arena-wide buff on that tier: <id>:<target> entries
# separated by |, e.g. bossWaveBuff3=frost:players|bloodlust:monsters. Targets
# are players, monsters or both; an omitted target means players. Unlike the
# wave spawns, the tiers REPLACE one another — each threshold switches the
# previous tier's buffs off as it switches its own on, so exactly one tier's
# aura is ever live. Its own key rather than a sixth bossWaveN field, so files
# exported before the feature still round-trip. Written only for tiers that
# carry one: the stock defaults buff only the boss-death tier, so the horde that
# spawns after the kill fights bloodlusted on the walk to the orb.

# bossWavePickup1..5 drops items on that tier: <item>:<count> entries separated
# by |, e.g. bossWavePickup3=powerup_health:1|mana_2:2. An omitted count means
# one. The copies land on the drop pad just inside the arena entrance the moment
# the threshold fires and stay on the floor until somebody walks over them, so
# unlike the buffs above the tiers do NOT replace one another. The pad is the
# same layout on every seed — health up the left, mana up the right, upgrades in
# the middle, potions in the bottom row by the door — so it can be learnt once
# and run back to. Its own key, and written only for tiers that drop something,
# for the same round-trip reason as bossWaveBuff. The stock table resupplies at
# 50%, hands out one rejuvenation potion at 25%, and doubles the resupply once
