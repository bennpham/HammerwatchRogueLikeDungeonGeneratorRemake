# Boss invulnerability: at 75%, 50% and 25% health the boss goes immortal for
# this many seconds, with a ticking countdown announced to the party. It stops a
# fully upgraded party bursting the boss down before the fight happens, and it
# keeps the three thresholds from firing in the same frame — which would switch
# every wave tier on at once and flood the arena. One value sets all three
# thresholds; three set them separately; 0 disables that one threshold; `off`
# disables the feature entirely.
bossInvuln=30,30,30
# 0 keeps the immortality windows but drops the countdown announcements (one
# script node per second, per window).

# The arena's own multipliers, separate from the dungeon's monsterMultiplier /

# endless -1 stays endless), bossFoodMultiplier the arena's health/mana pickups.

# whole group across the arena at once and ignore the intervals. A monster whose
# wreck still blocks movement (the nova/frost/tracking towers) may not be
# scattered. A max of -1 means endless, and cannot be combined with a scatter
# mode. An empty wave is legal and emits nothing.
